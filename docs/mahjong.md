# 新余麻将牌室

入口 `/mahjong`，邀请链接 `/mahjong/<32位随机房间号>`。四人固定座位，普通站点账号登录即可使用。房主创建后邀请朋友，其他玩家准备后开局；空位可以由机器人补齐。开局后不接纳新玩家，暂离的原玩家可回座。

这是站主确认的「新余自摸家规」实现，各家细则通过房间选项明确展示，不宣称统一覆盖所有新余地方玩法。固定 136 张（万、筒、条各 36 张及字牌 28 张），无花、无精、不可吃。

## 默认和可选规则

默认 4 局、基础 1 分、留 16 张荒牌、只自摸、明杠/补杠每家 1 分、暗杠每家 2 分。流局也计杠分，可改为「有人胡牌才计杠分」。所有杠分在本局结算明细中统一列出。

房主可在开局前调整：

- 1/4/8/16 局，基础 1/2/5/10 分，留 0/8/16/20 张荒牌。
- 只自摸或允许点胡；点胡时可选一炮多响、抢补杠胡。暗杠和明杠不能被抢。
- 明杠/补杠 0/1/2 分，暗杠 0/1/2/4 分；三家各付，乘基础分。杠分不参与胡牌倍数封顶。
- 七对 ×4、豪华七对 ×8、门清 ×2、碰碰胡 ×2、混一色 ×2、清一色 ×4、全字牌 ×8、金钩钓 ×4、开杠 ×2、杠上开花 ×2，均可单独开关。
- 倍数按相乘计算，8/16/32/64 倍封顶后乘基础分。豪华七对替代普通七对；全字牌替代清一色/混一色。暗杠仍算门清。自摸其他三家各付一份，点胡由放铳者支付一份。
- 每次出牌 30/60/90 秒，响应 8/12/20 秒；赢家坐庄（流局连庄）或每局轮庄。

保存新规则会取消其他玩家的准备状态。开局后不能修改本桌规则。仅以本桌显示的规则及结算明细为准；当前未实现精牌、十三烂、十三幺、掷骰定位补牌、地方包牌或其他未列出的变体。

## 操作与习惯

庄家 14 张，其他玩家 13 张。摸牌在手牌最右侧标记；选择手牌后须点「打出某牌」确认。碰后须先出牌，不能立刻暗杠或补杠。明杠、暗杠、补杠都从牌尾补牌，剩余可摸牌不足时不允许杠。

自己坐在屏幕下方，三位对手围坐，四家的弃牌和手牌背面各自归位。桌中央显示倒计时、当前方向和还能摸多少张。手机可点右上角「横屏」进入全屏；浏览器不支持锁定方向时，把手机横过来即可使用横屏布局。竖着也能打。

第一次操作牌桌后，开启的报牌会念出各家刚打出的牌，包括机器人的出牌。右上角扬声器可静音，偏好保存在本机。34 句固定普通话报牌由 [eSpeak NG](https://github.com/espeak-ng/espeak-ng) 离线生成，网页只加载静态音频。

从右上角「聊天」发送文字或快捷表情。每条文字最多 80 个字符，牌桌只向已入座的玩家显示最近 48 条；关闭牌室后不可查看，记录随牌室到期清理。聊天不打断出牌，也不改变牌局版本。

有响应时全桌等待；胡牌优先于碰/杠，不能以请求先后抢走胡牌。点胡多响关闭时，按放铳者下家起的座次优先。超时默认过；出牌超时打出刚摸到的牌，碰后超时打最右手牌。机器人会自行胡牌、碰杠和出牌；只使用自己的手牌和公开信息作决策，不读牌墙或其他人的手牌。

本局结算后显示四家手牌和胡牌、杠分明细。房主手动开下一局。返回大厅会保留座位；明确离开牌室后由机器人接管，原账号可经邀请链接回座。房主离开则转交给下一位真人。没有真人或 30 分钟无人查看/操作时关闭牌室；记录保留到 7 天到期。

## 服务、持久化与测试

使用现有 Node 24 + SQLite，无需新增数据库、第三方账号或额外服务。使用表 `mahjong_rooms`、`mahjong_members`、`mahjong_ops`、`mahjong_chat`；房间状态、手牌、牌墙、积分、规则和版本都在服务端保存。发布重启后可恢复；过期的出牌/响应时限会按超时规则推进。

所有写操作使用现有登录、来源与 CSRF 检查。操作带房间版本和随机操作编号，服务端事务处理，重复请求不重复出牌或计分。公开响应仅包含本人的手牌、其他人的手牌数量、弃牌及明牌。对手暗杠隐藏牌面，结算后才公开。机器人不产生新增用户/参与数据；真人每局首次实际出牌/响应记一次游戏参与，麻将入口在原增长统计中单列。

`tests/mahjong.test.mjs` 覆盖和牌识别、碰杠胡优先级、三种杠、抢杠、荒牌与杠分、30 场完整机器人对局的 136 张守恒及积分守恒、会话/CSRF、准备、房主权限、重试与旧版本、回座、重启恢复、封禁与过期。

```sh
node --test tests/*.test.mjs
```

通用摸打与杠后补牌机制参考 [波克麻将规则](https://mm.pook.com/gbmj/rule/rule-2.html)；此参考的国标计分和吃牌规则不作为本桌规则使用。新余地方口述细则存在差异，因此未列明的玩法不自行套用。
